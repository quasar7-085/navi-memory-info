개인정보처리방침

시행일: 2026-10-09

1. 처리 목적과 범위

Navi Memory Backup은 검증된 기억 변경 기록을 Google Drive에 백업하고, 그 백업을 복구 대기열로 검증하기 위해서만 데이터를 처리합니다. 전체 대화, 전체 Drive, 첨부파일을 자동으로 수집하지 않습니다.

2. Google 데이터와 권한

앱은 drive.file 권한으로 앱이 만든 백업 파일·폴더를 처리합니다. 이 권한은 사용자가 앱으로 열거나 만든 다른 파일에 적용될 수 있으나, 현재 프로그램은 자체 생성한 비공개 백업만 대상으로 합니다.

계정 이메일, 파일 소유자·공유·부모·크기·해시 정보는 올바른 계정인지 확인하고 백업의 무결성을 검증하는 데 사용합니다.

3. 보관과 접근

기록은 연결한 소유자의 Drive에 개인·팀별 비공개 폴더로 보관합니다. 전송 대기 상태는 소유자가 운영하는 시스템에 보관되며, 최종 기억은 소유자의 로컬 시스템에 보관됩니다. 인증 파일은 전용 관리자 계정만 읽을 수 있도록 저장하고, AI 모델이나 팀 봇에 제공하지 않습니다.

4. 공유와 사용 제한

개인 기록을 팀 기억에 자동 복사하지 않습니다. 백업 파일을 자동 공유하거나 광고·판매·일반 AI 모델 학습에 사용하지 않습니다. Google 데이터는 백업과 복구 기능에만 사용하며, Google API Services User Data Policy의 Limited Use 요건을 따릅니다.

5. 연결 해제와 삭제

소유자는 Google 계정의 연결 관리 화면에서 앱 권한을 취소할 수 있습니다. 해제하면 새 전송은 중단되지만 기존 Drive 백업은 자동 삭제되지 않습니다. 소유자는 Drive에서 해당 백업 폴더를 삭제하고, 서버 대기 기록·인증 삭제 요청을 이 저장소의 Issues로 남길 수 있습니다. 자동 보존기간 만료·삭제 기능은 현재 제공하지 않습니다.

6. 변경과 문의

수집·이용 범위가 바뀌면 이 문서와 계정 동의 설정을 함께 갱신합니다. 공개 문의는 GitHub Issues를 사용합니다.
